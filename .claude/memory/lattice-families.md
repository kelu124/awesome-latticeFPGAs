Boards in this awesome list are filed by Lattice FPGA family. Section header → part:

- iCE40: `HX1K`=iCE40HX1K, `HX4K`=iCE40HX4K, `HX8K`=iCE40HX8K, `LP384`=iCE40LP384,
  `LP1K`=iCE40LP1K, `LP4K`=iCE40LP4K, `LP8K`=iCE40LP8K, `UL1K`=iCE40UL1K (UltraLite),
  `UP5K`=iCE40UP5K (UltraPlus, the largest section).
- `CrossLink-NX` = LIFCL (e.g. LIFCL-40).
- `ECP5` = LFE5U / LFE5UM / LFE5UM5G.
- `LFE3` = LatticeECP3 (mostly commercial TV-tuner cards).
- `MachXO2` currently appears under the commercial "Others" bucket, not its own section.

`Other commercial products` is a separate top-level section for shipping gear (not dev boards)
containing a Lattice FPGA, sub-grouped by family. If a board's part has no section yet, add a new
`## Header` — new categories are welcomed. See [[list-conventions]].
